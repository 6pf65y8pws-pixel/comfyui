# 大食いチャレンジ ─ Belly Buster

ブラウザで動く単一ファイルの大食いゲーム。ベルトコンベアで流れてくる料理を食べて、
90 秒でどこまでお腹を大きくできるかを競う。溜まったガスは **ゲップ** で逃がす。

`games/big-eater/index.html` を直接ブラウザで開くだけで遊べる。ビルド不要、外部依存なし。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 皿をクリック / タップ | 料理を食べる。満腹度とスコアが上がる |
| `SPACE` またはゲップボタン | ゲップしてガスを放出する |
| お腹をドラッグ | なでるとガスが少しずつ抜ける |
| `M` | ミュート切り替え |

- **満腹度** がそのままランクとスコアの土台になる。
- **ガス** は炭酸・ビールで一気に増える。100% でギブアップ＝ゲーム終了。
- ガス 70% 以上でゲップすると「ナイスゲップ」ボーナス。溜めてから出すほど高得点。
- 連続で食べるとコンボ倍率がかかる（途切れるまで 2.6 秒）。

## 実装メモ

- 描画はすべて Canvas 2D の手続き的描画。画像アセットは一切なし。
  絵文字だけはフォント（🍜🍔…）をそのまま描いている。
- 効果音は WebAudio の合成。ゲップはブラウンノイズを帯域変調（鋸波 LFO で
  バンドパスの中心周波数を揺らす）し、喉のフォルマントと低域ランブルを重ねて作っている。
  強さ（ガス量）で長さ・ピッチ・音量が変わる。
- 体型は次のレイヤ順で描く。お腹を胴体とは別パスにすることで、
  ウエストに乗った「はみ出し」と落ち影が自然に出る。

  ```
  背面の腕 → 胴体 → ショートパンツ → お腹の落ち影 → お腹
      → 肌の陰影 → タンクトップ → 前面の腕 → 汗
  ```

- 腕は 2 関節 IK。手首は必ず届く距離に丸めてから描くので、
  ターゲットが遠くても棒のように伸びない。
- お腹の揺れは減衰バネ 2 本（横・縦）で、食べた瞬間とゲップに力積を与えている。

### パフォーマンス

`ctx.filter = blur()` はソフトウェア描画だと非常に重い。そこで

- 人物は等倍のオフスクリーンキャンバスに描いてから拡大合成する
  （ぼかしのコストが端末の DPR に引きずられない）
- グラデーションで済むところはぼかさない
- それでも 1 フレーム 24ms を超える状態が 24 フレーム続いたら
  自動的にぼかしを切って実解像度描画に切り替える

### 開発用

`?debug=1` を付けて開くと `window.__DBG` から内部状態を触れる。

```js
__DBG.set(0.9, 0.8);   // 満腹度 90% / ガス 80%
__DBG.doBurp();
__DBG.setBlur(false);  // ぼかしを切って計測
```
