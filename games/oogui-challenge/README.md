# 大食いチャレンジ / Gorge & Belch

食べてお腹を膨らませ、たまったガスをゲップで逃がすタイムアタックゲーム。
外部ライブラリ・外部アセットなしの単一 HTML ファイル。

## 遊びかた

`index.html` をブラウザで開くだけ（ビルド不要、オフラインで動く）。

| 操作 | 内容 |
| --- | --- |
| 食べ物ボタン / `1`〜`8` | 食べる。満腹度とガス圧が上がる |
| ゲップボタン / `Space` | ガスを一気に逃がす。抜いた量に応じて加点 |
| キャンバスをドラッグ | お腹をなでる。消化が約3倍速くなるが、ガスも早く上がってくる |

## ルール

- **満腹度** か **ガス圧** が 100% に達したらギブアップ（ゲーム終了）。
- 満腹度は時間とともに消化され、その一部が **ガス圧** に変わる。放っておいても圧は上がる。
- ゲップは溜まっているガスが多いほど長く・低くなり、得点も大きい（44 以上で「ビッグゲップ！」ボーナス）。
  ガスが 7 未満だとスカって加点なし。
- 続けて食べるとコンボ倍率が上がる（最大 ×2.6）。3.2 秒食べないとリセット。
- 制限時間 70 秒以内に目標スコアへ届けばステージクリア。
  ステージが進むと消化が遅く、ガスは溜まりやすく、一口が大きくなる。

## 実装メモ

- **キャラクター**: 首から下を Canvas 2D で毎フレーム手描き。輪郭は片側 17 点の
  制御点を Catmull-Rom でベジェに変換し、左右対称にミラーして閉じている
  （`halfOutline` / `bodyPath`）。
- **ソフトボディ**: 満腹度＋ガス圧を目標値とするバネ・ダンパ（減衰比 ≈0.58）で
  お腹の膨らみが行き過ぎて揺り戻す。食べた瞬間とゲップの瞬間に力積を与え、
  進行する正弦波の波紋（`B.rip` / `B.ripPh`）を輪郭の各点にその点の柔らかさ
  `soft` で重み付けして適用している。ゲップでは縦につぶれて横に広がる。
- **陰影**: 光源は左上固定。お腹の球体グラデーション、脇腹と胸下のぼかした
  アンビエントオクルージョン、張った皮膚のツヤ、苦しさの赤み（`soft-light`）、
  ストレッチライン、膨らむほど横に伸びるおへそ、全体に乗せる粒子ノイズ。
- **服**: 裾の高さ `hemAt(x)` と襟ぐり `neckAt(x)` の 2 本の曲線で布の領域を作り、
  お腹が育つと裾がめくれ上がる。ボトムスのウエストバンドは逆に押し下げられ、
  食い込みの影とせり出したお腹の落とす影が乗る。
- **サウンド**: すべて WebAudio で合成、音声ファイルなし。ゲップはノイズを
  ローパス＋バンドパスに通し、鋸波 LFO で振幅をばたつかせて喉の震えを作り、
  `WaveShaper` で歪ませ、サブベースで体の重みを足している。ガス量で長さ・
  フィルタ・LFO 周波数が変わるので、大きいゲップほど長く低い。
  ほかに咀嚼音、嚥下音、腹鳴り。
