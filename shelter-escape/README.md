# 地下シェルター脱出ゲーム（プロトタイプ）

React + TypeScript + Vite。1人用、セーブなし、ポイント&クリック。

体重は食べることでしか増えず、**一度増えた体重は元に戻らない**。出口ごとに必要な体格が違うので、
プレイヤーはどこかで「もう食べない」と決めることになる。

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # ロジックと人体の不変条件テスト
npm run build      # 型チェック + 本番ビルド
```

## いま出来ているところ（仕様書 §10 の 1〜3）

- 型定義と `useReducer` の骨格
- 部屋3つ（食堂 / 保管庫 / 配電室）、段階3まで
- エンディング2つ（通風ダクト / 非常階段）
- コアループの確認：**棚を押せない → 食べる → 押せる → でもダクトに戻れない**

仕様書 §10 の指示どおり、ここで一度止めてある。段階4〜6・主搬入口・残りの部屋は次のフェーズ。

### 仕様書との差分（意図的なもの）

| 箇所 | 仕様書 | 実装 | 理由 |
|---|---|---|---|
| プロトタイプのエンディング | ダクトのみ | ダクト＋非常階段 | ダクトだけだと段階3で出口が無くなり、§6「詰み防止の保証」を破るため。配電室の先はもともと階段へ繋がる |
| キャラクター画像 | 段階ごとの差分画像（プロトタイプは矩形プレースホルダ可） | パラメトリックSVGで6段階を生成 | 「リアルに、人体に破綻を生むな」という追加指示に対応。差し替え用の画像が来たらここだけ入れ替えられる |
| `GameState` | 5フィールド | +3（`solvedHotspotIds` / `pendingFoodId` / `endingId`） | その場で解決するギミックと確認ダイアログの状態に必要。`types.ts` に「追加」と明記 |

`localStorage` は使っていない。効果音・BGM・ランダム要素・戦闘・時間制限・リソース管理も無し（§11）。

## 構成

```
src/
  game/          ロジックとデータ（描画に依存しない）
    types.ts       仕様書 §6 の型定義
    stages.ts      段階テーブル。duct/climb を失う段階はここだけで決まる
    rooms.ts       部屋・食料・エンディングの定数。ロジックは書かない
    reducer.ts     useReducer 本体
    reachability.ts 到達可能な状態を全探索する（詰み検出用）
    game.test.ts
  art/           絵。ゲームロジックからは独立
    physique.ts    6段階の体型定義（実測値ベース）
    figure.ts      骨格＋体型 → SVGパス生成
    Figure.tsx     人物の描画（陰影・輪郭光・着衣）
    geometry.ts    曲線生成の下請け
    scenery.tsx    部屋の描画部品
    RoomArt.tsx    3部屋の絵
    figure.test.ts 人体の不変条件テスト
  components/    UI
```

## 設計上の要点

**段階3で `duct`、段階4で `climb` を失う。** これが「食べない選択」に意味を与えている唯一の仕組みなので、
緩めてはいけない（仕様書 §3）。`stages.ts` の1テーブルだけがこの挙動を決めている。

**詰みは機械的に検出する。** `reachability.ts` が到達可能な状態を全探索し、
`game.test.ts` が「どの状態からも最低1つのエンディングに行ける」ことを検査する。
部屋や食料を足したときに詰みが生まれたら、テストが落ちる。

**人体は「骨格固定・脂肪分布可変」で作る。** 関節位置（`figure.ts` の `SK`）は全段階で共通で、
段階ごとに変えるのは脂肪の付き方・姿勢・服の合い方だけ（`physique.ts`）。
段階ごとに手描きパスを用意すると必ずどこかで破綻するので、その構造を取っていない。
腕が胴に飲み込まれないよう、腕は体幹輪郭の外へ押し出す規則を入れてある。
`figure.test.ts` が関節位置のズレ・末端の異常肥大・輪郭の破綻を検査する。

体型は単なる拡大ではなく段階ごとに別物として定義している：

| 体重 | 腹 | その他 |
|---|---|---|
| 62kg | 平ら | 鎖骨と頬骨が出る。手足が細い |
| 78kg | ほぼ平ら | 輪郭が滑らかになる |
| 95kg | 前に丸く出る | 顎の下に肉。上着が引き攣る |
| 118kg | 大きく前方へ | ウエスト幅が胸郭を追い越す。首が肩に埋まる。上着が閉まらない |
| 150kg | 下垂して大腿にかかる | 胸部脂肪。腕が体側に下ろせない。足幅を広げて支える |
| 190kg | 大腿中央まで下垂 | 頸部が脂肪に埋もれる。自力の移動が困難 |
