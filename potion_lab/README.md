# 🧪 もちもち調合工房 — Potion Lab

素材を集めてポーションを調合し、お客さまに飲んでもらって体の変化を観察・記録する、
ブラウザだけで動く調合シミュレーションゲームです。

外部ライブラリ・画像素材・ビルド作業は一切不要。`index.html` を開くだけで遊べます。

```
potion_lab/index.html   ← これをブラウザで開く
```

> ローカルファイル (`file://`) でもそのまま動きます。
> セーブ (localStorage) を確実に動かしたい場合は簡易サーバー経由がおすすめです。
>
> ```bash
> cd potion_lab && python3 -m http.server 8899   # → http://localhost:8899/
> ```

## ゲームの流れ

| # | 手順 | 画面 |
|---|------|------|
| 1 | **素材を集める** — 採取地を選んで行動力を1消費 | 🌿 採取 |
| 2 | **ポーションを調合する** — ベース＋素材3つまでを組み合わせる | ⚗️ 調合 |
| 3 | **お客さまに飲んでもらう** — 対象を選んで試飲 | 🍶 試飲 |
| 4 | **変化を観察・記録する** — 変化量とセリフが図鑑に残る | 📔 記録 |
| 5 | **新しい素材・レシピ・お客さまを解放** — 研究目標の達成報酬 | 🏆 依頼 |

行動力は 1 日 4 ぶん。使い切ったら **🌙 就寝** で翌日へ進みます（就寝時に効果が少しずつ抜けていきます）。

## ステータス

| ステータス | 内容 |
|---|---|
| 🎈 **膨満度** | お腹の張り。上がるほど体の輪郭が前にせり出します |
| 🍰 **むちむち度** | 全身のふくよかさ。手足・顔つきまで変化します |
| 💨 **ガス圧** | 溜まるほど自然に漏れます。押すと出やすくなります |
| 🍡 **もちもち度** | 柔らかさ。高いほど大きく・長くぷるぷる揺れます |
| 💗 **ごきげん** | 高いほど薬がよく効き、低いと抵抗されます |

段階は `ふつう → ぽっこり → ぱんぱん → ぱつぱつ → 限界突破` の5段階。
段階が上がるごとに専用のセリフと表情が用意されています。

## もちもち感について

お腹は **バネ質点を環状につないだソフトボディ** として計算しています。

- お腹を **クリック／ドラッグ** すると、押した場所がへこみ、波が左右に伝わって揺れます
- **もちもち度が高いほど** バネが柔らかく減衰が小さくなり、ゆっくり長く揺れます
- 呼吸・待機中のゆらぎ・薬を飲んだときの膨張の脈動も同じ物理で動きます
- 体の輪郭は「胴体のプロファイル」と「腹部のふくらみ」を滑らかに合成して1本の線として描くので、
  膨らんでも継ぎ目のない体型になります

効果音（ぷにっ／ごくごく／ぷすー等）はすべて **WebAudio による合成音** で、音声ファイルはありません。
右上の 🔊 で切り替えられます。

## 調合のコツ

- **同じ系統の素材を重ねる** とシナジーで効果が増幅します（例：ふくらみ草＋風船の実）
- **ベース**で方向性が変わります
  - 💧清らかな水 … 素直
  - 🥛濃厚ミルク … むちむち＋もちもち強化
  - 🫧炭酸水 … 膨満＋ガス強化
  - 🍵ハーブティー … 効果が長持ち・ごきげん上昇
- ⚡雷茸＝即効性、🌙月光露＝持続、🪨重力石の粉＝安定、🧪消化酵素＝元に戻す
- お客さまごとに **耐性・代謝** が違います。同じ薬でも結果が変わります

## ファイル構成

```
potion_lab/
├── index.html      画面構成
├── style.css       スタイル（ダークテーマ・レスポンシブ）
└── js/
    ├── data.js     素材・採取地・ベース・キャラクター・セリフ・研究目標
    ├── render.js   ソフトボディ物理／SVGキャラクター描画／効果音合成
    └── game.js     ゲーム進行・UI・セーブ（localStorage）
```

セーブは `localStorage` の `potion_lab_save_v1` に自動保存されます。
右上の ↺ で最初からやり直せます。
