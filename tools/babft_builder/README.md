# babft_builder — 3Dモデルをブロック建築に変換する

3Dモデル（`.glb` / `.gltf` / `.obj` / `.stl` / `.ply`）を読み込んで、**傾けて伸ばしたブロックの集合**に変換します。
Build A Boat For Treasure のようにブロックの回転とサイズ変更ができる環境向けなので、
階段状のボクセルではなく、曲面を「角度のついた板」の集まりとして近似します。

Python 3.10 以上があれば動きます。追加パッケージは不要です（Pillow が入っていれば JPEG テクスチャも読めます。
PNG は同梱のデコーダで読むので何も入れなくて構いません）。

## 使い方

```bash
# 基本（一番長い辺が 40 スタッドになるように変換）
python -m tools.babft_builder boat.glb

# 大きめ・ブロック数を 300 個以内に抑える
python -m tools.babft_builder boat.glb --size 80 --max-blocks 300

# 15度刻みでしか回せない場合は角度をスナップ
python -m tools.babft_builder boat.glb --angle-step 15

# 色数を絞る（塗れる色が限られているとき）
python -m tools.babft_builder boat.glb --colors 12

# 箱組み（グリッドに揃えたい、カクカクのモデル向け）
python -m tools.babft_builder boat.glb --mode voxel --resolution 32 --solid
```

入力ファイルと同じ場所に、同じ名前で 4 つのファイルが出ます（`--out` で出力先、`--formats` で種類を指定）。

| ファイル | 用途 |
| --- | --- |
| `*.html` | ブラウザで開く3Dプレビュー。ドラッグで回転、ホイールで拡大縮小。スライダーで組み立て順に1個ずつ表示できるので、これを見ながら手で建てられます |
| `*.txt` | ブロック一覧。1行1ブロックで「サイズ / 位置 / 角度 / 色」。下から順に並んでいます |
| `*.lua` | Roblox Studio 用スクリプト。貼り付けて実行すると、そのままパーツが生成されます |
| `*.json` | 生データ。自分でツールを書くとき用 |

## Roblox Studio で使う

1. Studio でプレイスを開き、**View → Command Bar** を出す
2. `*.lua` の中身を全部貼り付けて Enter
3. `workspace` にモデルが生成されます（全パーツ Anchored）

スクリプト先頭の `SCALE` と `ORIGIN` を書き換えれば、生成サイズと位置を後から調整できます。

## ゲーム内で手で建てるとき

`*.html` を開いて、右のスライダーを 1 から順に上げていくと、そのブロックだけが増えていきます。
一覧の各行がそのブロックの「サイズ（幅×高さ×厚み）/ 位置 / 角度」なので、それを見ながら同じ形のブロックを置いていきます。

- 角度は **X, Y, Z の順に回した度数**（Roblox の `CFrame.Angles` と同じ並び）です
- 位置は建築物の底面中央が原点（Y が高さ）
- ゲーム側の回転が刻み単位なら `--angle-step 15` などで最初から丸めておくと、見た目のズレが出ません

なお、このツールは**設計データを出すところまで**です。動作中のゲームクライアントを操作してブロックを自動配置する機能は入っていません（Roblox の利用規約に反するため）。

## 変換のしくみと調整

`--mode plates`（既定）は、隣り合う三角形のうち「向きが近く」「同じ平面に近い」ものをまとめて 1 枚のパネルにし、
そのパネルに最小面積の長方形を当てはめて 1 ブロックにします。曲面は、少しずつ角度の違うパネルの集合になります。

ブロック数と再現度は、主に次の 2 つで決まります。

- `--flat-tol` … パネルの平面からどれだけ膨らんでもよいか（スタッド単位、既定は `--size` の 2%）。大きくすると 1 枚が広くなり、ブロックが減る代わりに角ばります
- `--angle-tol` … 何度まで向きが違う面を同じパネルに入れるか（既定 20 度）
- `--fill` … パネルが実際に覆っている面積の何倍まで大きくなってよいか（既定 2.0）。ブロックは長方形なので、いびつな形にまとまったパッチほど余分がはみ出します。下げるとブロックは増えますが、形からのはみ出しが減ります

数を先に決めたいときは `--max-blocks 300` のように指定すると、その数に収まるまで自動で許容値を緩めます。

`--mode voxel` は格子で埋める方式です。同じ色の隣接セルは 1 個の伸ばしたブロックにまとめられるので、
`--colors` を指定するほどブロック数が減ります。`--solid` で内部も詰めます。

## オプション一覧

```
--size N            一番長い辺の長さ（スタッド、既定 40）
--up y|z            元データの上方向の軸（既定 y。Blender 由来の STL などは z）
--mode plates|voxel 変換方式（既定 plates）
--colors N          色数の上限（0 で無制限）
--angle-step D      回転を D 度刻みに丸める（0 で自由角度）
--material NAME     Studio スクリプトで使う Enum.Material 名
--out DIR           出力先ディレクトリ
--name NAME         出力ファイル名のベース
--formats a,b,c     lua,html,json,txt から選択

plates:
--thickness N       パネルの最小厚み（既定 0.5）
--angle-tol D       面をまとめる角度の許容（既定 20）
--flat-tol N        平面からのずれの許容（既定 --size の 2%）
--fill N            パネルが覆っている面積の何倍まで許すか（既定 2.0）
--min-area N        これより小さいパネルは捨てる
--max-blocks N      この個数に収まるまで許容値を自動で緩める

voxel:
--resolution N      一番長い辺のセル数（既定 40）
--solid             内部も埋める
--no-merge          セルを結合せず 1 セル 1 ブロックにする
```
